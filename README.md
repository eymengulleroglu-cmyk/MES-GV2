# MES-G — Üretim Yürütme Sistemi (MES)

Küçük ve orta ölçekli imalat işletmeleri için üretim yürütme sistemi (MES) prototipi.

## Teknoloji
- React + TypeScript + Vite
- Tailwind CSS (açık/koyu tema)
- React Router, React Query, Recharts

## Çalıştırma
```bash
npm install
npm run dev
```
Üretim derlemesi:
```bash
npm run build
```

## Modüller (MVP)
- Pano (KPI özet)
- Üretim Emirleri (liste + detay)
- İş Merkezleri (liste + detay, adet +/-)
- Duruş & Fire kayıtları
- Ayarlar (tema, demo verisi sıfırlama)

## Demo verisi
Tüm veriler sentetik demodur. Gerçek şirket/müşteri/tedarikçi verisi kullanılmaz. Ayarlar ekranından sıfırlanabilir.
